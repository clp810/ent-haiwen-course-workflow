# Haiwen Project Context

本页只提供课程工作流需要的去个人化项目背景，不记录个人信息或个人叙事。

## 项目定位

Haiwen 是面向计划出海或已经开展海外业务的中国人工智能企业的产品概念，关注出海合规与 ESG 合规支持。它试图降低企业获取、理解和使用海外合规信息的门槛。

## 要解决的问题

相关要求分散在法规原文、监管指南、行业标准、客户问卷和专业服务中。团队关注的不只是找到信息，还包括判断适用性、识别缺失信息、形成下一步行动，并在高风险或高不确定性问题上升级到具备相应资质的专业人员。

## 产品方向

课程讨论可使用以下尚待验证的产品方向：

- 结构化的法规知识、工具和材料；
- 带来源的 AI 检索与初步解释；
- 结合企业情境的追问、缺口识别和行动建议；
- 面向复杂问题的专业工单；
- 必要时连接真人专家复核。

Haiwen 不替代律师、审计师、税务师或认证机构，也不应把无法核验来源、版本和适用条件的模型回答当作专业结论。

## 课程使用边界

上述内容用于帮助成员把课程方法应用到同一项目背景。具体用户画像、需求强度、采用意愿、付费意愿、市场规模、产品效果和商业成果都需要新的、可追溯证据，不能仅凭项目设想写成已验证事实。
